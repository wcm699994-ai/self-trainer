# SelfTrainer

SelfTrainer 是一款将「机器学习模型训练范式」迁移到个人行为优化的极简工具。

用户像调试模型一样迭代自身行为秩序：去道德化、去鸡汤、不依赖意志力，通过量化指标与梯度微调实现稳定收敛。

## 核心特性

- **双指标体系**：损失指标 + 增益指标，各最多 3 项，总计不超过 6 项
- **梯度微调建议**：纯本地规则引擎，采用目标偏差率 + 7日滑动中位数方案，单次调整幅度不超过当前值 20%
- **每日数据采集**：结构化数字录入，7 天内补录，草稿自动保存，支持一键复制昨日（仅数值）；实时显示与目标的达标状态
- **周复盘**：损失/增益双趋势曲线 + 单指标走势（含目标参考线），基础规则复盘 + 可选 AI 深度复盘
- **本地优先**：核心闭环 100% 本地运行，断网可用
- **PWA 支持**：可添加到主屏幕，离线可用（内置 192/512 PNG 图标）
- **AI 可选增强**：固定 DeepSeek 官方服务，仅用于辅助生成指标与深度复盘
- **使用说明页**：内置完整操作指南
- **数据主权**：数据全部存储在浏览器本地 IndexedDB，支持 JSON/CSV 导出备份（CSV 含全部历史指标列，导入支持覆盖/合并双模式）

## AI 配置说明

SelfTrainer 已固定使用 DeepSeek 官方服务：

- API 地址：`https://api.deepseek.com/v1`
- 模型：`deepseek-v4-flash`

只需在「配置」页填写 DeepSeek API Key 即可启用 AI 增强功能。

AI 仅在以下两个场景由用户手动触发：

1. 配置页：AI 辅助生成指标
2. 复盘页：AI 深度复盘分析

无有效 API Key、网络错误、超时、调用失败时，AI 入口自动隐藏或显示重试按钮，核心功能不受影响。AI 生成失败时可展开查看原始返回内容，便于定位问题。

## 数据存储与隐私

- 每日记录：IndexedDB（不可用时自动降级 localStorage，恢复后自动合并，避免数据分裂）
- 数据模型：历史记录以「指标 ID」为主键——改名、删除后重建、重新导入模板都不会切断历史数据
- 配置、API Key、草稿：localStorage
- 所有数据仅留存于用户本地浏览器，不上传任何服务器
- API Key 明文存储在 localStorage，请勿在不受信任的设备上使用
- AI 请求仅发送必要的结构化数值数据，不包含用户身份信息

## 定位诚实说明

本工具的「梯度微调」本质上是基于目标偏差率与滑动中位数的启发式规则，并非数学意义上的梯度下降。我们借鉴了 ML 训练的概念框架，但实现上采用工程化直觉与行为心理学原则，旨在提供稳定、可解释的微调建议。
